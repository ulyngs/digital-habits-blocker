Welcome to ReDD Block 2.0

A one-time cleanup is needed to finish your upgrade.

ReDD Block now blocks websites through a browser extension instead of a system-level helper. We need to:

  • Stop and remove the old privileged helper
  • Restore your /etc/hosts file (a backup is kept)
  • Keep all your existing blocklists intact

You'll see one admin password prompt. Blocking will pause briefly during the changeover. After cleanup, you'll need to install the ReDD Focus browser extension.

How to install

  1. Click Copy URL next to a browser below.
  2. Open that browser.
  3. Paste the URL into the address bar and press Enter.
  4. Click Add to … (or Add to Firefox / Get for Safari) on the page that loads.
  5. Allow ReDD Focus in incognito mode (otherwise you can just open an incognito tab to see any blocked site...).
  6. Come back here and click I've installed it.
