Welcome to ReDD Block 2.0

A one-time cleanup is needed to finish your upgrade.

ReDD Block now blocks websites through a browser extension instead of a system-level helper. We need to:

  • Stop and remove the old privileged helper
  • Restore your /etc/hosts file (a backup is kept)
  • Keep all your existing blocklists intact

You'll see one admin password prompt. Blocking will pause briefly during the changeover. After cleanup, ReDD Block sets up the ReDD Focus browser extension in your browsers automatically — you just need to allow it in private/incognito tabs.

Setting up ReDD Focus

  1. ReDD Block tried to add ReDD Focus to your installed browsers automatically — restart each browser to pick it up.
  2. Once enabled, allow it in private/incognito tabs so blocking works in private windows too.
Browser enforcement To help you stay focused, your browser is automatically closed if you turn off ReDD Focus while a block is running.

Once on, you can only turn enforcement off when no blocks are running.
